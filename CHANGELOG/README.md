# 📜 The PAI Chronicles — a Living History

> Every entry is a chapter, not a changelog. Each proves itself by
> commit or URL. No claim survives that cannot show its scar.

## How to read this book

Each entry is filed by date as `YYYY-MM-DD-title.md`, written in the
voice of the founder of the fortress — the one who watched the city
rise from a single tent upon the sand.

Every entry ends with the **Witness** — the commit hash, the URL, the
test that proves the words true. A claim without a witness is a ghost,
and ghosts are not welcome here.

## How to add a chapter

1. `git log --since 24h --pretty=format:"%h %s"` across pai-list repos.
2. Read the week through its atoms — search `boundaries/thoughts/` if you
   must, but prefer the code itself.
3. Write the story. Then write the Witness.
4. Name your file `YYYY-MM-DD-title.md`, link it in the table above,
   and elevate the newest chapter to the top.

> **Rule of the Inkwell:** the entry must read like a friend telling you
> what changed last week — not like a machine dumping structs. If a
> chapter could have been written by a bot that never ran the code,
> rewrite it. The Chronicle is human-first, compression second.
