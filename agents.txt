## Architecture (7-Layer Memory)

L1: sqlite-vec (hot) - Local agent memory
L2: Ghost.build pgvector (warm) - Relational + vector memory
L3: Neon (facts) - Long-term factual memory
L4: Qdrant (code) - Code embeddings
L5: Sigstore (trust) - Verifiable audit trail
L6: Firestore (state) - Global state
L7: R2+Parquet (archive) - Cold storage
